# Flake for Windows — техническое задание

## 1. Назначение проекта

Flake — небольшое Windows-приложение на C# и WPF, которое отображает анимированный снег поверх рабочего стола. Приложение должно работать как ненавязчивый прозрачный overlay, не блокировать взаимодействие пользователя с окнами и предоставлять основные команды через системный трей.

## 2. Целевая платформа и технологии

- ОС: Windows 10 и Windows 11.
- Архитектура поставки: Windows x64.
- Язык: C#.
- UI и отрисовка: WPF.
- Платформа .NET: .NET 10 (`net10.0-windows`).
- WinForms используется только для значка и меню системного трея (`NotifyIcon` / `ContextMenuStrip`).

## 3. Функциональные требования

### Этап 0. Базовая версия и инфраструктура

- Создать прозрачное окно-overlay, покрывающее виртуальный рабочий стол.
- Отображать анимированные снежинки с разным размером, скоростью, дрейфом и прозрачностью.
- Сделать overlay прозрачным для кликов мыши.
- Добавить управление через системный трей: пауза/возобновление снегопада и выход из приложения.
- Подготовить структуру решения, README и CI-сборку под Windows.

**Критерий готовности:** приложение запускается на Windows, снег визуально отображается поверх рабочего стола, клики проходят сквозь overlay, команды системного трея работают.

### Этап 1. Настройка погоды

- Переключение направления ветра: слева направо и справа налево.
- Регулировка скорости ветра.
- Регулировка размера снежинок.
- Регулировка скорости падения снежинок.
- Три готовых режима: лёгкий снег, обычный снег и метель.
- Применение настроек без перезапуска приложения.

**Критерий готовности:** все настройки меняют поведение снегопада; переключение режимов и ручные регуляторы работают без зависаний и заметных визуальных артефактов.

### Этап 2. Накопление снега

- Снежинки оседают у нижней границы экрана и накапливаются при столкновении с поверхностью.
- Сугробы постепенно увеличиваются по мере выпадения снега.
- Поверхность снежного слоя неровная и со временем меняет форму, а не остаётся прямой линией.
- Высота накопления ограничена, чтобы снег не закрывал большую часть рабочего стола.
- Добавить команду полной очистки накопленного снега через системный трей.
- Слой должен корректно переживать изменение размеров области отрисовки в пределах текущего сеанса.

**Критерий готовности:** при длительном снегопаде слой заметно растёт и меняет форму; частицы взаимодействуют с текущей поверхностью; команда очистки убирает весь слой без перезапуска; overlay продолжает пропускать клики.

### Этап 3. Снежки и снеговики

- Реализовать ручной сбор снега: в режиме «Варежка» пользователь зажимает левую кнопку мыши на накопленном слое и ведёт курсор по сугробу.
- Удалять снег с поверхности по траектории руки и передавать собранный объём во временный формируемый шар, который растёт и следует за курсором.
- При отпускании кнопки превращать сформированный шар в физический объект; не создавать снежки через команду или спавн.
- Реализовать перетаскивание сформированных снежков мышью с передачей скорости после отпускания.
- Добавить движение под действием гравитации, качение по наклону снежной поверхности и ограничение границами экрана.
- Реализовать столкновения снежков с учётом их массы и упругости.
- Предусмотреть дополнительный сбор снега при качении и постепенное увеличение радиуса.
- Автоматически собирать снеговика из трёх устойчиво расположенных снежных шаров разного размера.
- Сохранять click-through в остальной области overlay; временно включать WPF-взаимодействие в узкой зоне поверхности снега и над готовыми снежными объектами.

**Критерий готовности:** шар появляется только после сбора реального снега с поверхности; пользователь может сформировать шары разного размера, перетаскивать и перекатывать их; три подходящих шара собираются в снеговика; обычные клики по рабочему столу не блокируются.

### Этап 4. Сохранение и удобство запуска

- Сохранять настройки погоды между запусками.
- Реализовать сохранение снежного слоя между запусками либо явно определить условия его сброса.
- Добавить опцию запуска вместе с Windows.
- Подготовить установщик и механизм удаления приложения.

**Критерий готовности:** пользовательские настройки восстанавливаются после перезапуска; поведение сохранения снега предсказуемо; установка, автозапуск и удаление работают штатно.

### Этап 5. Стабилизация и совместимость

- Проверить нагрузку на CPU и память при длительной работе.
- Проверить работу на Windows 10 и Windows 11.
- Проверить конфигурации с несколькими мониторами и разными масштабами DPI.
- Проверить корректность при изменении разрешения, отключении/подключении мониторов, сворачивании и блокировке сеанса.
- Устранить найденные ошибки, утечки ресурсов и заметные артефакты.

**Критерий готовности:** приложение стабильно работает в целевых конфигурациях и проходит сборку и ручные проверки без блокирующих дефектов.

## 4. Ограничения текущей реализации

- Настройки погоды пока не сохраняются после завершения приложения.
- Слой снега хранится в памяти и сбрасывается при выходе из приложения.
- Ручное лепление снежков и сборка снеговика добавлены в development-ветку; сборка проекта и проверка взаимодействия на Windows ещё требуются.
- Фактическая визуальная проверка выполняется на Windows-компьютере; статическая проверка исходников не заменяет GUI-тестирование.

## 5. Текущий статус

- Этап 0: базовая реализация создана; базовый снегопад проверен пользователем на Windows.
- Этап 1: реализация в коде завершена; требуется ручная проверка настроек на Windows.
- **Этап 2: реализация в коде завершена; требуется ручная проверка накопления, изменения формы сугробов и команды очистки на Windows.**
- Этап 3: ручной сбор снега, формирование снежков, физика и сборка снеговика добавлены в ветку `feature/snowballs-and-snowmen`; CI-сборка и ручная проверка на Windows ожидаются.
- Этапы 4–5: не начаты.

## 6. Дополнительные улучшения интерфейса и поведения (без нового этапа)

Эти изменения относятся к качеству уже реализованных функций и не меняют нумерацию основных этапов.

- Добавить настраиваемую свободную зону экрана над общим снежным слоем. Пользователь задаёт процент высоты экрана, который должен оставаться чистым; слой не может пересечь установленную границу. Будущие отдельные сугробы/объекты должны получить собственные ограничения, независимые от общего снежного слоя.
- Сделать очистку накопленного снега плавной анимацией, а не мгновенным сбросом профиля.
- Добавить переключатель ветра. При включении горизонтальный ветер меняет силу порывами; при выключении остаётся только естественное небольшое колебание снежинок.
- Добавить взаимодействие с курсором: снежинки отталкиваются от указателя в режиме «Разбрасывание снега»; в режиме «Варежка» пользователь зажимает левую кнопку мыши и собирает накопленный снег по траектории курсора в формируемый шар. Взаимодействие должно отключаться в настройках; ввод перехватывается только на поверхности сугроба и при перетаскивании готовых объектов, остальная область overlay сохраняет сквозные клики.
- Локализовать интерфейс на английский (язык по умолчанию), русский и украинский языки без флагов.
- Добавить в окно настроек вкладку-инструкцию и отдельную вкладку выбора языка. Смена языка применяется без перезапуска.

**Статус:** реализация включена в текущий maintenance update; требуется ручная проверка на Windows. Настройки по-прежнему не сохраняются после выхода из приложения.

- Взаимодействие с курсором использует глобальное чтение позиции указателя для переключения hit-testing в области снега. Режим «Разбрасывание снега» отталкивает частицы; режим «Варежка» включает WPF-захват мыши только на поверхности сугроба и позволяет собирать снег по траектории зажатой кнопки. Остальная область overlay остаётся click-through. Функцию можно полностью отключить в настройках.
